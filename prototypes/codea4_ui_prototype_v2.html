CodeA4

a system for rendering source code in the author's own handwriting

status — idle, no job running

Summary. CodeA4 scans a handwriting sample, learns its natural variation and drift, and renders uploaded source files onto print-ready A4 pages that look genuinely handwritten. No syntax colouring, no reformatting — whitespace and indentation are preserved exactly as written in the original file.

1. Capture

Step 1 of 5

We use the same short copying exercise for all three sheets, because knowing exactly what you were meant to write is what lets us measure your letterforms and how your lines drift, without guesswork.

1.1 Exercise sheet

Copy this exactly onto a blank sheet of A4, then photograph it.

Q1. Write a hello world program in C, including a comment
explaining what printf does.

Ans:
#include<stdio.h>
int main() {
    printf("Hello, world! 123 && done.\n");  // prints the message, then moves to a new line
    return 0;
}

Note the second line of the answer is written to run past a natural margin — this is deliberate, so we can observe how you actually wrap a line by hand.

2.2 Drift model

Solid line: baseline drift, vertical, within a line. Dashed line: margin drift, horizontal, down the page. Both curves are mean-reverting — a gradual wander followed by a gradual correction, never a snap back to the line.

4. Preview

Step 4 of 5

Style shifts only at natural breaks — such as a new function — never letter by letter. This preview uses generic fonts as a proxy; real output uses your own extracted glyph vectors.

main.py

Style 1 (upright) is used for the def block; Style 2 (bolder, slanted) for the class block. Long lines wrap naturally at the page edge, as they would on paper — no continuation marker.
